# PTE FIB-L Chunk 听写｜科学优化版 v4

## 核心训练逻辑
- 练习时显示英文 Chunk，只隐藏答案词，模拟 PTE FIB-L 的视觉语境。
- 首次听写出错即自动加入收藏错词，并记录累计错误次数与最近错误日期。
- 收藏页支持：全部收藏 / 听写错题 / 手动收藏 / C 类重点 / 到期复习。
- 收藏列表可以按最近收藏、错误次数、主题、原序号排序，并可直接从当前筛选结果开始听写。

## 判级
- A：首次作答正确 + 实际只播放 1 遍 + 未用慢速 + 未看中文提示。
- B：第二次才拼对，或重复播放、慢速、中文提示后拼对；仅凭文字语境未播放音频答对也只记 B。
- C：最终仍未拼对。
- 自动判级可以手动降级，但不能把使用辅助后的题强行升级。

## 间隔复习
- A：连续 A 后按约 3 → 7 → 14 → 30 天复习。
- B：约 1 天后复习，并重置 A 连续掌握计数。
- C：立即进入待复习；若本组后面至少还有 4 道题，则隔至少 4 道别题再次出现，否则留到下一轮，避免刚看答案就立刻重复造成假掌握。
- 普通“智能”顺序：到期复习 → 未学新词 → 尚未到期的弱词 → 已掌握词。
- 收藏“智能弱项”顺序：到期 → C → B → 手动收藏未学 → A。

## 数据
- 内置 915 个答案词。
- 学习数据保存在浏览器 localStorage。
- 可导入/导出学习进度 JSON 和题库 JSON。
- 旧版学习进度键保持兼容，不会因为升级网站自动清空。
